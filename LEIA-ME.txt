PHD ACADEMY — PACK COMPLETO KINGHOST
=====================================

VERSÃO
Site institucional + painel administrativo próprio + páginas automáticas de eventos.

TECNOLOGIA
- Front-end: HTML/CSS/JS
- Back-end: PHP
- Banco: MySQL/MariaDB
- Painel: /admin
- Página dinâmica de evento: /evento.php?slug=nome-do-evento

O PAINEL PERMITE
- Criar evento
- Editar
- Duplicar
- Excluir
- Ativar/desativar
- Destacar na Home
- Ordenar
- Upload de imagem
- Data
- Horário
- Cidade
- Endereço
- Formato
- Categoria
- Descrição curta
- Descrição completa
- Speaker
- Biografia do speaker
- Programação
- Investimento
- Link de compra
- Status

PÁGINAS "SAIBA MAIS"
Não precisam ser criadas manualmente.
Ao cadastrar um evento, o sistema gera automaticamente um slug e a página passa a existir em:

https://SEU-DOMINIO/evento.php?slug=nome-do-evento

O botão "Saiba mais" da Home abre automaticamente essa página.

INSTALAÇÃO NA KINGHOST

1. No painel KingHost, crie um banco MySQL/MariaDB.
2. Anote:
   - host do banco
   - nome do banco
   - usuário
   - senha
3. Abra:
   /config/database.php
4. Preencha os dados do banco.
5. Importe:
   database.sql
6. Envie todo o conteúdo do pacote para a pasta pública do domínio.
7. Garanta permissão de escrita na pasta:
   /uploads/eventos/
8. Acesse:
   https://SEU-DOMINIO/setup-admin.php
9. Crie usuário e senha do administrador.
10. APAGUE setup-admin.php imediatamente após criar o usuário.
11. Entre em:
   https://SEU-DOMINIO/admin/

REQUISITOS RECOMENDADOS
- PHP 8.1 ou superior
- PDO MySQL habilitado
- MySQL ou MariaDB
- HTTPS/SSL ativo
- mod_headers opcional

SEGURANÇA INCLUÍDA
- Password Hash / Verify
- PHP Sessions
- session_regenerate_id
- PDO Prepared Statements
- CSRF no salvamento
- Upload apenas JPG/PNG/WEBP
- Limite de 5 MB por imagem
- Bloqueio de listagem de diretórios via .htaccess
- Cabeçalhos básicos de segurança

IMPORTANTE
Se você já tiver instalado uma versão anterior deste projeto e criado as tabelas, NÃO importe este database.sql por cima sem migrar o banco. Esta versão adiciona novos campos.
Para uma instalação nova, use o database.sql deste pacote.
